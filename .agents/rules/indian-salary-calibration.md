# Indian Tech Market Salary Calibration Rules

1. **Currency & Unit**: Express compensation in Indian Rupees (`₹` / `INR`) using Lakhs Per Annum (`LPA`).
2. **Experience Tiers**:
   - Junior Engineer (0–2 Yrs): ₹6.50 LPA base
   - Mid-Level Engineer (3–5 Yrs): ₹12.50 LPA base
   - Senior Engineer / Lead (6–9 Yrs): ₹22.00 LPA base
   - Staff / Principal Architect (10+ Yrs): ₹36.00 LPA base
3. **Increments**:
   - Experience Premium: +₹1,20,000 per year of experience.
   - Core Talents & Skill Premium: +₹80,000 per Must-Have skill satisfied.
4. **Strict Exclusion**: Do NOT include merit match score percentage multipliers in base CTC calculation.
